# Tower of Hanoi — Python Game Development

## Deskripsi

Tower of Hanoi adalah game puzzle 2D yang dibuat menggunakan bahasa pemrograman Python dan library Pygame. Tujuan permainan ini adalah memindahkan semua cakram dari tiang A ke tiang C dengan bantuan tiang B.

## Tujuan

* Menerapkan logika permainan dalam Game Development.
* Memahami penggunaan library Pygame untuk membuat game 2D.
* Menerapkan aturan perpindahan objek berdasarkan ukuran cakram.
* Membuat sistem penghitung langkah dan kondisi kemenangan.

## Aturan Permainan

1. Pemain hanya boleh memindahkan satu cakram dalam satu langkah.
2. Pemain hanya boleh memindahkan cakram paling atas.
3. Cakram besar tidak boleh diletakkan di atas cakram kecil.
4. Permainan selesai ketika semua cakram berada di tiang C.

## Fitur Game

* Visualisasi tiga tiang dan cakram.
* Kontrol menggunakan mouse.
* Validasi perpindahan cakram.
* Penghitung jumlah langkah.
* Pesan kemenangan.
* Tombol reset untuk mengulang permainan.

## Teknologi

* Python
* Pygame

## Cara Menjalankan

1. Pastikan Python sudah terinstal.

2. Instal library Pygame menggunakan perintah:

   `python -m pip install pygame`

3. Jalankan program menggunakan perintah:

   `python tugasgamedev.py`

## Kesimpulan

Game ini merupakan implementasi puzzle Tower of Hanoi untuk mempelajari dasar Game Development, seperti pengelolaan objek 2D, input mouse, game loop, validasi aturan, dan kondisi kemenangan.
